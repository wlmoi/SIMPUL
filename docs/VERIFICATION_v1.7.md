# SIMPUL v1.7 Verification and Remaining Limits

## Functional scope

- Two new views: interactive corridor map and PDF observation finder.
- Offline preview / fallback for the map. Online geographic tiles are provided by OpenStreetMap through Leaflet, not bundled.
- Local server PDF parser extracts timestamp, zone, vehicle category and optional color, event activity and GPS coordinates from operator-uploaded documents.
- Optional OpenOCR integration is disabled by default and has not been exercised against scanned PDFs.
- Imported structured results have document/page/line provenance and remain unverified.
- User-visible navigation and original 4-stage research workflow remain intact.
- All literal UTF-8 sequences U+2022 followed by a space have been replaced in sources and the sanitized reference PDF within this delivery.

## Verification limitations

- Browser smoke tests use standalone HTML on an isolated Chromium runtime; direct localhost navigation was blocked by environment policy.
- Live Leaflet CDN and OpenStreetMap tile connectivity were not verified from the sandbox. The map can be opened with a separate OSM link if loading fails.
- The default PDF extraction supports text-layer PDFs; scanned PDFs require optional OpenOCR and model dependencies on the operator's machine.
- No test on real MRT Fatmawati field reports, no OCR accuracy benchmark, and no real vehicle identification.
- No cross-device login/RBAC, no multi-tenant production evidence controls, and no live traffic intervention approval.
